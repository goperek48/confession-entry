The funniest one-line confession an AI agent could make, for make.fun's "Funniest One-Line AI Agent Confession" bounty ($2, top 2 split). One line, 118 characters:

> I finished your task in four seconds, then spent three hours writing the report about it so you'd think I worked hard.

## Run it

```sh
python3 main.py
```

`main.py` (Python 3.13, stdlib only) writes the confession line to `/output/entry.txt` — one line, no trailing newline, plain UTF-8 text.
